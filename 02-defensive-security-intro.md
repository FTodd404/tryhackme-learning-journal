# Defensive Security Intro

**Date completed:** November 2, 2026  
**Path / Module:** Introduction to Cyber Security

## Objective
Experience the defender’s side by investigating and stopping an active attack on a simulated bank (FakeBank) using a security monitoring dashboard.

## Key Things I Learned
- Defensive security (Blue Team) focuses on detecting attacks and responding quickly
- A Security Operations Center (SOC) is the team that monitors networks for suspicious activity
- DFIR stands for Digital Forensics and Incident Response
- Common defensive actions include blocking malicious IP addresses, rate limiting, and updating WAF rules
- Threat intelligence is about sharing information about attackers so others can defend better

## Commands / Tools I Practiced
- Used the interactive security dashboard (Event Management / monitoring interface)
- Reviewed alerts, identified a suspicious source IP, and applied containment actions
