# Offensive Security Intro

**Date completed:** November 2, 2026  
**Path / Module:** Introduction to Cyber Security

## Objective
Get a first hands-on taste of offensive security by legally hacking a simulated banking website (FakeBank).

## Key Things I Learned
- Offensive security means thinking like an attacker to find weaknesses before real attackers do
- Hidden or unlinked pages on websites are a common and serious vulnerability
- Simple tools can uncover pages that were never meant to be public
- Even basic web applications can have dangerous business-logic flaws (like unrestricted money transfers)
